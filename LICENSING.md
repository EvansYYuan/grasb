# Licensing

GRASB is a mixed-license repository because it combines original GRASB work
with a transport engine derived from GPL-licensed ARTEMIS code.

## Original GRASB contributions

Original GRASB software, configuration, evaluation, and figure-generation code
authored for this project is available under the MIT License in `LICENSE`,
unless a file or directory states otherwise.

GRASB-authored modifications within a GPL-covered file are also offered by the
GRASB authors under MIT. That additional grant does not remove rights held by
earlier authors or change the license of the combined file.

## GPL-covered transport engine

Files in `engine/` that contain or derive from ARTEMIS or `unbalanced_sb` code
must be treated as GPL-3.0-covered when distributed as combined files. The GPL
text is in `LICENSE-GPL-3.0`. Programs distributed as a combined or derivative
work with that engine must satisfy GPL-3.0, even when GRASB-authored components
are also available separately under MIT.

The upstream `unbalanced_sb` MIT notice is preserved in
`THIRD_PARTY_UDSB_LICENSE`; see `THIRD_PARTY_NOTICES.md` for provenance.

## Manuscript, figures, data, and third-party materials

The software licenses above do not automatically relicense the manuscript,
publication figures, datasets, marker sources, or other third-party content.
Those materials retain their stated source terms. A license selected for an
OpenReview submission applies according to the scope stated by that submission
form.
